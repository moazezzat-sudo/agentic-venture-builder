# Interview Scheduler Guide: user guide

## What it is

A lightweight Flask‑based web application that lets small‑to‑medium HR teams create interview slots, share a public booking link, generate iCal files, and export schedules as CSV.

## How to use it

1. Install the required Python packages with pip.
2. Configure the database (SQLite for local testing or PostgreSQL for production).
3. Run the Flask app and register HR users via the built‑in login system.
4. Create interview slots using the provided form (date, start time, duration).
5. Share the generated public URL (/book/<slot_id>) with candidates so they can book a slot.
6. Download the schedule as CSV or iCal from the admin interface.

## Limits

- This is a draft generated by an AI agent; the founder reviews and edits it before anyone uses it.
- The idea needs a full app. Only the smallest working piece is built here: A markdown document outlining the architecture, required Python packages, database schema, and a simple Flask app skeleton that implements user authentication, interview slot creation, a public booking link, iCal export, and…
- Does not include any built‑in video‑call or remote interview integration.
- No support for multiple time‑zone handling beyond the server’s local time.
- Only basic email notifications via Flask‑Mail; no templating or bulk email features.
- No role‑based access beyond simple admin/member distinction.
- Scales only as far as the underlying Flask and database setup allow; no built‑in load‑balancing or clustering.
